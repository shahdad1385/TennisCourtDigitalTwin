# Reference photographs — credits and licences

Ten photographs of clay tennis courts (*terre battue*, orange-red crushed brick)
used as the objective colour/lighting reference set for the ClayTennis UE 5.5
project.

* **Source:** Wikimedia Commons (all files are freely licensed; none are fair-use).
* **Fetched by:** `Tools/download_refs.ps1` from the pinned list in `manifest.json`.
* **Machine-readable twin:** `manifest.json` (same fields, one entry per file).
* **Analysis outputs:** `palette.json`, `PALETTE.md`, `swatch.png`.

> The image CDN only responds if requests carry a normal browser `User-Agent`
> **and** a `https://commons.wikimedia.org/` `Referer`; the download script sets both.
> Flickr, Pexels, Unsplash and Pixabay CDNs were unreachable from the build
> machine, so every asset below comes from Wikimedia Commons.

## Provenance / reproducibility

1. `manifest.json` pins each `ref_NN.jpg` to one Commons file, so re-running
   `Tools/download_refs.ps1` never renumbers or duplicates anything.
2. Every download is verified: JPEG magic bytes (`FF D8 FF`), decodes through
   `System.Drawing`, and both dimensions exceed 800 px — this rejects HTML error pages.
3. Images are **measurements**, not art direction: `Tools/analyze_refs.ps1`
   samples every 4th pixel of the central crop to derive the palette.
